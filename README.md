# EAN Regional Teaching Course 2026 — Exam Prep

Study site for the **EAN Regional Teaching Course** (3–5 September 2026, Istanbul University, Beyazıt) and its optional multiple-choice examination.

**Live site:** enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) and open the published URL on your phone.

## Contents

- **Cheat Sheet** — session-by-session summaries of all three course days (MS biomarkers & imaging · NMOSD/MOGAD · autoimmune & paraneoplastic encephalitis), built from the photographed course slides, the scientific program, and current diagnostic criteria. English terminology with short Turkish notes.
- **Quiz** — 56 exam-style multiple-choice questions with instant feedback and explanations.

## Sources

- `docs/` — photos of the course slides (HEIC) and the scientific program PDF
- Course website: https://tndean-bolgeselegitimkursu.org

## Run locally

Open `index.html` directly, or:

```sh
python3 -m http.server
```
